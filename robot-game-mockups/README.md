# Bolt Buddies: robot-building game concepts

PNG mockups for a kids' robot-building game. Everything is drawn in code (SVG + CSS): robots, icons, buttons and backgrounds. Nothing comes from stock art.

| File | Screen |
|---|---|
| `00-overview.png` | All screens on one board |
| `01-home.png` | Home / title |
| `02-adventure-map.png` | Adventure map (no level numbers) |
| `03-robot-workshop.png` | Drag-and-drop build workshop |
| `04-reward-stars.png` | Stars and rewards |
| `05-robot-garage.png` | Robot collection and paint |
| `06-settings.png` | Settings (music, sounds, rate us, share) |
| `07-art-kit.png` | Parts, UI kit, sound list, palette |
| `00b-game-loop.png` | Build → launch → fly → repair → rewards |
| `09-launch-pad.png` | Countdown and launch |
| `10-space-flight.png` | Flying in space: stars, shield, comets, UFO |
| `11-sky-flight.png` | Flying in the sky: rings, balloons, combos |
| `12-crash-repair.png` | A bump knocks a part off, so kids fix it |

Re-render with `cd src && node render.js` (uses the Playwright Chromium). Fonts: Lilita One and Fredoka (SIL OFL).
